# Chess Tactics Puzzle Trainer

Train your chess tactics with 15 pre-built mate-in-1 puzzles displayed on an 8x8 board using Unicode chess pieces.
Click a piece to select it, then click the target square; the app checks if it matches the solution and tracks solved count, accuracy, and streak.
Up to 3 hints per session highlight the piece to move; all stats persist in localStorage (`ctpt_data`).
